# RACI Matrix — GRC Program Activities

`R` = Responsible · `A` = Accountable · `C` = Consulted · `I` = Informed

| GRC Activity | CISO | VP Compliance | GRC Analyst | IT Manager | Engineering Lead | Legal Counsel | Internal Audit |
|---|---|---|---|---|---|---|---|
| Policy Development | A | R | R | C | C | C | I |
| Risk Assessment | A | R | R | C | C | C | I |
| Control Testing | I | A | R | C | C | I | C |
| Vendor Risk Assessment | A | R | R | C | I | C | I |
| Audit Support | I | A | R | R | C | C | R |
| Compliance Monitoring | I | A | R | C | I | C | C |
| Incident Response Governance | A | C | R | R | R | C | I |
| Executive Reporting | A | R | R | I | I | I | C |
| Training & Awareness | A | R | R | C | C | I | I |
| Policy Exception Management | A | R | C | C | C | C | I |

This matrix is reviewed annually and updated upon organizational changes. It is the single source of truth for "who owns what" across the entire GRC program — every deliverable in this repository maps back to a row here.
